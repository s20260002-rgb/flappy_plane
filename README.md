# Flappy Plane

A tiny one-button jet game. Fly a Boeing 303-style twinjet through glass skyscrapers — and watch them explode if you clip one.

**Play online:** https://s20260002-rgb.github.io/flappy_plane/

## Controls

- **Click / tap / Space / Up** — boost
- **P or Esc** — pause
- **M** — mute

Built as a single self-contained HTML file with Canvas and Web Audio. No dependencies, no build step — just open `index.html`.
